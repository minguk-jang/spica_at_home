Judge + done() Verifier, Completion Check, Eval 성공 종료/실패 종료/재시도 여부를 판정

sequenceDiagram
    actor User
    participant O as Agent loop
    participant P as plan_update
    participant A as Specialist Agent
    participant G as Guardrail
    participant X as Tools.act Adapter
    participant V as Judge

    User->>O: 업무 요청
    O->>P: step 계획 갱신
    P->>A: step assign
    A->>G: action 제안

    alt 고위험 액션
      G-->>User: confirm 요청
      User-->>G: 승인/거부
    end

    G->>X: Tools.act 실행
    X-->>V: result + artifact
    V-->>O: pass/fail

    alt fail
      O->>P: replan/retry
    else success
      O-->>User: 최종 결과
    end
