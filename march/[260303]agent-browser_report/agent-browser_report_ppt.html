Overview

이 시스템은 무엇인가?

"웹 브라우저 조종 로봇"에 가깝습니다. 사람이 하는 브라우저 작업을 명령으로 변환해 백그라운드 데몬이 실행하고, 결과를 구조화된 JSON으로 반환합니다.

Insights

핵심 인사이트

강점

  • CLI-데몬 분리로 성능/확장성 확보
  • Ref 기반 상호작용으로 LLM 안정성 강화
  • 보안 장치(action policy, origin/session 검증)
  • 관측성 도구(screenshot/video/diff/trace) 풍부

주의점

  • 134개 액션의 유지보수 비용 증가
  • 프롬프트 소스 분산(docs-chat/skills/eval)
  • iOS/Appium/Xcode 환경 의존성
  • 멀티 에이전트 엔진으로 오해 가능

결론 한 줄

agent-browser는 "에이전트를 위한 브라우저 실행 플랫폼"이며, 명령-정책-실행 분리 구조가 기술적 핵심입니다.
