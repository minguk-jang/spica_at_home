# 구현 세부사항

## 주요 구현 결정 사항

### 1. WXT 0.20.x에서 Storage 처리

**문제**: WXT 0.20.x에서 `wxt/storage` export가 제공되지 않음

**해결**:
```typescript
// utils/storage.ts
import { type RecordingState, DEFAULT_RECORDING_STATE } from './types';

const STORAGE_KEY = 'recordingState';

export async function getState(): Promise<RecordingState> {
  const result = await browser.storage.local.get(STORAGE_KEY);
  return (result[STORAGE_KEY] as RecordingState | undefined) ?? DEFAULT_RECORDING_STATE;
}

export async function setState(state: RecordingState): Promise<void> {
  await browser.storage.local.set({ [STORAGE_KEY]: state });
}

export function watchState(callback: (state: RecordingState) => void): () => void {
  const listener = (changes: Record<string, Browser.storage.StorageChange>, area: string) => {
    if (area === 'local' && changes[STORAGE_KEY]) {
      callback(changes[STORAGE_KEY].newValue as RecordingState);
    }
  };
  browser.storage.onChanged.addListener(listener);
  return () => browser.storage.onChanged.removeListener(listener);
}
```

### 2. WXT Auto-Import 이름 충돌

**문제**: WXT가 자동으로 컴포넌트와 타입을 전역 import하여 `StepGroup` 컴포넌트와 `StepGroup` 인터페이스가 충돌

**해결**: 타입 이름을 `StepGroupData`로 변경
```typescript
// utils/types.ts
export interface StepGroupData {  // StepGroup → StepGroupData
  id: string;
  name: string;
  icon: string;
  steps: Step[];
  collapsed: boolean;
}
```

### 3. Browser 타입 네임스페이스

**문제**: TypeScript에서 `browser.Runtime.MessageSender` vs `Browser.runtime.MessageSender` 혼동

**해결**: WXT의 Browser 타입은 소문자 namespace 사용
```typescript
// ❌ 잘못된 사용
sender: browser.Runtime.MessageSender

// ✅ 올바른 사용
sender: Browser.runtime.MessageSender
```

```typescript
let inputDebounceTimer: ReturnType<typeof setTimeout> | null = null;

function onInput(e: Event) {
  if (!isRecording) return;
  const target = e.target as HTMLInputElement | HTMLTextAreaElement;
  if (!target || !('value' in target)) return;

  if (inputDebounceTimer) clearTimeout(inputDebounceTimer);

      action: 'input',
      selector,

      value: target.value,
      url: window.location.href,

  }, 500);  // 500ms 디바운스
}
```

## 리플레이 엔진

### Input 값 설정 (네이티브 방식)
React 등 프레임워크의 controlled input을 위해 네이티브 setter 사용:
```typescript
if (action === 'input' && value !== undefined) {
  const input = el as HTMLInputElement;

  // 네이티브 value setter 사용 (React 호환)
  const nativeInputValueSetter = Object.getOwnPropertyDescriptor(
    window.HTMLInputElement.prototype,
    'value',
  )?.set;

  if (nativeInputValueSetter) {
    nativeInputValueSetter.call(input, value);
  } else {
    input.value = value;
  }

  // 이벤트 디스패치
  input.dispatchEvent(new Event('input', { bubbles: true }));
  input.dispatchEvent(new Event('change', { bubbles: true }));
}
```

```typescript
async function ensureContentScript(tabId: number): Promise<void> {
  try {
    // content script가 이미 로드되었는지 확인
    await browser.tabs.sendMessage(tabId, { type: 'GET_STATE' });
```

### 리플레이 오케스트레이션
```typescript
async function replaySteps(tabId: number, steps: Step[]): Promise<void> {
  for (const step of steps) {
    await new Promise((resolve) => setTimeout(resolve, 500));  // 500ms 대기

    try {
      await sendToContentScript(tabId, {
        type: 'REPLAY_STEP',
        payload: {
          selector: step.selector,
          action: step.action,
          value: step.value,
          key: step.key,
        },
      });
    } catch (err) {
      console.error(`[AI Recorder] Replay failed for step: ${step.label}`, err);
      // 오류가 있어도 계속 진행
    }
  }
}
```

### JsonPanel 복사 기능
```typescript
export default function JsonPanel({ step }: JsonPanelProps) {
  const [copied, setCopied] = useState(false);

  const jsonData = step
    ? {
        intent: step.label,
        selectors: [step.selector],
        action: step.action,
        ...(step.value && { value: step.value }),
        ...(step.key && { key: step.key }),
      }
    : null;

  const handleCopy = async () => {
    if (!jsonData) return;
    await navigator.clipboard.writeText(JSON.stringify(jsonData, null, 2));
    setCopied(true);
    setTimeout(() => setCopied(false), 1500);
  };

  return (
    <aside>
      <span onClick={handleCopy}>
        {copied ? 'check' : 'content_copy'}
      </span>
      {/* JSON display */}
    </aside>
  );
}
```
