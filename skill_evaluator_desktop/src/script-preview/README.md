# Script Preview Rules

This folder owns every UI-facing script preview generated by WebMCP Desktop.

Rules:

1. A preview is one Python + Playwright file, not JavaScript.
2. `run_handler` steps must not be hidden behind handler imports.
3. Every referenced handler module must be inlined as real Python code in the
   preview. Function bodies must remain executable `def ...` blocks, not
   commented source text.
4. If the source file cannot be read, the preview must generate a real Python
   stub function that raises `RuntimeError` with the missing handler id.
5. Resource templates and step JSON must stay visible near the generated script
   so the DB workflow can be audited without opening another file.

The Electron main process enriches sidecar handler metadata with `sourcePath`
and `sourceText` before the renderer calls `generatePlaywrightScriptPreview`.
